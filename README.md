# Hotel Salta

Página básica de un hotel hecha con React, JavaScript, CSS y React Router.

## Cómo iniciar

Desde la carpeta app-hotel:

```powershell
npm start
```

No se agregaron dependencias nuevas.

## Cómo funciona

1. Entrar al inicio o a Habitaciones.
2. Hacer clic en una foto o en Reservar.
3. Elegir las fechas de ingreso y salida.
4. Completar nombre y apellido, correo y teléfono.
5. Presionar Confirmar reserva.

Se muestra el mensaje **¡Tu reserva ya está registrada!**. Es solamente una simulación: no se envían datos ni se genera una reserva real.

La estructura y el código se explican en [ARQUITECTURA_BASE.md](./ARQUITECTURA_BASE.md).
